# 🗂️ Animated File Shredder

A modern and satisfying **Animated File Shredder** built using **HTML, CSS, and JavaScript**. Watch files smoothly move into the shredder with realistic animations, making a simple delete action feel fun and interactive.

## 🚀 Live Demo

https://yuktrium.github.io/Animated-File-Shredder/

## ✨ Features

- 🗂️ Smooth file shredding animation
- ✨ Interactive UI effects
- ⚡ Pure HTML, CSS & JavaScript
- 📱 Fully Responsive
- 🎨 Modern design
- 🔧 Easy to customize

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
